# XinPilot v1.0.2

RxnPilot is renamed to XinPilot. The TypeScript application, reaction sketcher,
launchers and executable use the new name. Launch with Launch_XinPilot.bat or
XinPilot-v1.0.2-Windows-x64.exe.

New portable projects use .xinpilot.zip. Existing .rxnpilot.zip, .syntrack.zip
and .oneclick.zip projects remain importable. The internal project format/version
is unchanged. Previous RxnPilot and SynTrack analytical peak bundles and
calculator transfer schemas remain readable. Tecan custom labware and liquid
classes fall back to existing RxnPilot settings; new settings use XinPilot.

Chemistry, transfer calculations and Opentrons nozzle-selection behavior are
unchanged. The explicit-push behavior introduced in v1.0.1 is retained.
GPT6 and API editions are outside this rename. Older releases are archived
separately; the GitHub source folder contains no executable or private data.
