# Known limitations

- An intermittent controller timeout has previously been reported. Unique dialog
  tokens, duplicate-response guards and nested-dialog restoration now address
  specific dialog races; this does not establish that every freeze is resolved.
- Long Windows paths can prevent extraction of deeply nested project assets.
  Use a reasonably short, writable folder.
- Older image-only analyses require reanalysis to supply numerical peak-inspection
  data. An MS feature need not have a UV-integrated area.
- Development-machine checks do not establish independent clean-PC installation,
  chemical assignment accuracy or robot execution.
- Separate orchestration/API development is not included in this desktop snapshot.
- External Import accepts supported transfer tables, not arbitrary native robot
  programs. One reaction destination plate is supported per import; volume units,
  source Chemical IDs and destination geometry require review. Physical robot
  coordinates are not inferred from numeric positions or vendor names.
