# XinPilot 1.2.2

Adds MassLynx/AutoLynx sample-list CSV export from LCMS Input, using reaction names and mapped LCMS wells. Includes method-only CSV template loading, explicit injection volume, plate position and format, injection order, and duplicate/missing-field validation.

Chemistry, PyParse and dispensing behavior remain unchanged. Existing v1.2.1 limitations documented in release-1.2.0.md remain. A Waters acquisition test and independent clean-PC test have not been performed.
