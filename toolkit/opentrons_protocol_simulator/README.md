# Opentrons Protocol Simulator

Independent, self-contained XinPilot Toolkit utility for simulating Opentrons `.py` and `.json` protocols without requiring a local Opentrons or conda environment.

The Toolkit copy contains the verified one-file simulator executable and its reference source. It accepts optional custom labware JSON files and writes simulation output only when the user selects **Save Output**. It does not read or modify XinPilot project data.
